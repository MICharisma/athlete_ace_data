# NBA logos and LeBron headshots

Captured November 15, 2026. This batch includes all 480 logo variants listed for the 30 teams in `sources/coverage_2026/nba.json`, one official NBA league SVG, and LeBron James's NBA and ESPN headshots. All 483 requested source files returned image content. No source was unavailable.

The team listing was captured October 26, 2026; this batch captures the referenced image bytes on November 15. It does not refresh rosters, certify current membership, establish logo introduction dates, or identify a historical jersey from a latest headshot.

## Sources and identity

- Team marks retain the original ESPN team-page URL, exact image URL, and provider relation labels. League-qualified team codes use the same abbreviation normalization as `scripts/build_2026.rb`.
- The league mark is `https://cdn.nba.com/logos/leagues/logo-nba.svg`, verified as SVG image content. Its source is the official NBA website.
- The official [LeBron profile](https://www.nba.com/player/2544/lebron-james) supplies `https://cdn.nba.com/headshots/nba/latest/1040x760/2544.png`. The NBA ID is 2544.
- The existing ESPN roster capture identifies LeBron as athlete 1966 and supplies `https://a.espncdn.com/i/headshots/nba/players/full/1966.png`. The provider IDs belong to their respective sources and are not interchangeable.
- Both portraits reference the existing `FIGURE-BKT-NBA-PLAYER-JAMES_LEBRON` identity. Its explicit catalog declaration binds the Figure already generated by the Player importer; it does not create a second person.

The Knicks default and secondary-on-white files matched the pilot URLs and SHA-256 checksums and reuse those two existing representations. All other requested files are pinned through `media.json`. The SVG remains the canonical source representation of the NBA mark; `renditions.json` separately records a PNG conversion for browser display, its source hash, conversion command, and media commit.

The November 16 supplement in `conferences.json` adds the Eastern and Western Conference wordmarks from Wikimedia Commons. Both source pages attribute the artwork to NBA Media Central. The Eastern original URL returned HTTP 403 and was recorded as unavailable. The Commons originals were downloaded and checked separately. The capture records their exact URLs, sizes, checksums, and pinned media commit. It does not establish current use or introduction dates.

No separate official mark was verified for any of the six NBA divisions. Their breadcrumbs keep the existing icon and text.

## Regeneration

From the application checkout, capture into the independent media checkout:

```sh
db/seeds/athlete_ace_data/.venv/bin/python db/seeds/athlete_ace_data/scripts/capture_nba_media.py --as-of 2026-11-15 --media-root ../athlete_ace_media
```

Use the actual observation date for a new capture. The command prints requested/available/unavailable counts and does not bypass HTTP failures. Review `capture.json` and the media diff, then commit and push the files. Set `media.json` to that exact full commit SHA. Keep independently generated renditions in `renditions.json` with their own pinned revisions.

Generate and check the seed output offline:

```sh
mise exec -- ruby db/seeds/athlete_ace_data/scripts/build_nba_media.rb
mise exec -- ruby db/seeds/athlete_ace_data/scripts/build_nba_media.rb --check
```

`--check` must exit zero and report the record, reuse, and selection counts. A nonzero exit means the committed output differs. The generator writes observation records to `yaml/nba_media_2026/media.yml`, the Figure identity to its canonical catalog file, and the 34 primary selections to `primary.json`.

After application migrations, import with `seeds:validate db:seed` and run `seeds:assets:verify` using the app's pinned Ruby. A replay must create zero records and report no seed conflicts. Primary selection replay must report all 34 unchanged. The complete library has 508 stored files after the conference supplement, including the earlier 24 pilot files, the PNG rendition, and the two conference wordmarks, with the two matching Knicks files reused.
